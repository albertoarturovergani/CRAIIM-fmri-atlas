# Licensing, upstream atlases, and redistribution

**No blanket open-source licence is granted here to the recovered CRAIIM NIfTI volumes, the original thesis, or conference posters.** The original data are an integration of third-party atlases. A public GitHub release of these binary assets must be preceded by verification of all applicable licenses and, if needed, explicit rightsholder permission.

As of November 2026, the FSL official license documentation identifies the Harvard–Oxford atlas as licensed under **CC BY-SA 4.0** and the Jülich histological atlas as subject to the **FSL noncommercial-use terms**. Applicable source versions, attribution notices and derivative-distribution obligations should be checked against the upstream resources used to generate these historical CRAIIM files.

- FSL license: https://fsl.fmrib.ox.ac.uk/fsl/docs/license.html
- FSL documentation: https://fsl.fmrib.ox.ac.uk/fsl/docs/
- Creative Commons BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/

## Recommended release procedure

1. Preserve the original recovered NIfTI bytes and checksums in a private archival location.
2. Verify attribution and permission to redistribute the Jülich-derived data and Harvard–Oxford derivative, including any noncommercial constraint and share-alike requirements.
3. Review copyright of archived posters, abstracts and other PDF/PPTX originals before making those assets public.
4. Publish author-prepared README, original scripts, thesis-derived label table, citation metadata and scientific methods documentation separately from the FSL-derived binary volumes. Review any incorporated third-party content and do not apply a blanket MIT/Apache license that purports to relicense atlas volumes.
5. If binary redistribution is not permitted, provide a documented retrieval/request procedure and cite the original sources rather than posting unauthorized assets.

This is a rights/provenance caution, not legal advice, and not a claim that redistribution is definitively forbidden. The exact applicable conditions should be verified with upstream maintainers and the rights holders.
